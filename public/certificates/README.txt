Place your certificate files here before building/deploying.

REQUIRED FILES:
===============

1. AWS Certified Cloud Practitioner (PDF):
   Filename: aws-clf-c02.pdf
   Also add a preview image (JPG/PNG):
   Filename: aws-clf-c02-preview.jpg

2. DigitalPe Internship Certificate (JPG or PDF):
   Filename: digitalpe-internship.jpg
   (If PDF, also save as JPG for the preview image)

After placing files, run: npm run build
